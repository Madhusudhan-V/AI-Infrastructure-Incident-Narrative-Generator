# Two-Month Development Roadmap

Weeks 1-2: architecture, live log generator, parser, watcher, tests.

Weeks 3-4: explainable rules, statistical anomaly detection, correlation, severity and confidence.

Weeks 5-6: SQLite persistence, incident lifecycle, local Ollama integration, evidence-grounded narrative, analyst review.

Weeks 7-8: HDFS experiments, evaluation metrics, dashboard analytics, exports/notifications, documentation, final demo and report.
